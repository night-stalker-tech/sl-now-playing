# PC Application

The **SL Now Playing PC Application** connects supported media playback on your Windows PC with the SL Now Playing HUD in Second Life.

The PC application is required for SL Now Playing to work.

---

## Download the PC Application

The PC application is downloaded through your **SL Now Playing HUD**.

1. Add the **SL Now Playing HUD** to your avatar in Second Life.
2. Use the **Download** option on the HUD.
3. A personal download page will open in your web browser.
4. Follow the instructions on the page to download the SL Now Playing PC application.

### Important

The download link generated by the HUD is temporary and can only be used once.

It is valid for approximately **5 minutes**.

If the link expires before you complete the download, simply use the **Download** option on the HUD again to generate a new link.

---

## Start SL Now Playing

After downloading the PC application:

1. Locate the downloaded SL Now Playing application on your computer.
2. Start the application.
3. Keep the application running while you use SL Now Playing in Second Life.

The PC application and your Second Life HUD will need to be paired before they can communicate.

[Continue to the Pairing Guide →](pairing.md)

---

## Windows Security

Depending on your Windows security settings, Windows may display a security message when you start the application for the first time.

Only use the SL Now Playing application downloaded through the official **TEKIZMO** download process.

---

## Download Link Expired?

No problem.

Return to Second Life and request a new download from the **SL Now Playing HUD**.

You do not need to reuse an expired download link.
