# Troubleshooting

Having trouble with **TEKIZMO – SL Now Playing**?

This page covers common problems and the first steps you can take to solve them.

---

## HUD Shows No Track Information

If music is playing on your PC but the HUD does not show the current track:

1. Make sure the **SL Now Playing PC Application** is running.
2. Make sure your SL Now Playing HUD is attached.
3. Make sure the HUD and PC application are correctly paired.
4. Check that media is currently playing.
5. Make sure you are using a supported player or playback source.

See:

[Supported Players](supported-players.md)

---

## HUD and PC Are Not Connecting

If your HUD cannot communicate with the PC application:

1. Make sure the PC application is running.
2. Check your internet connection.
3. Detach and re-add the SL Now Playing HUD.
4. Restart the PC application.
5. Try the pairing process again if necessary.

See:

[Pairing Guide](pairing.md)

---

## Media Is Detected Incorrectly

Some applications and browsers provide media information through the Windows media system.

Depending on the source, Windows may provide only generic or incomplete information.

If you are using browser playback, make sure the required **SL Now Playing Browser Bridge** is installed and active where applicable.

---

## YouTube Is Detected as Generic MEDIA

If YouTube playback appears only as generic **MEDIA** instead of being recognized correctly, check the SL Now Playing Browser Bridge.

For Firefox, make sure the Browser Bridge is installed and active.

Without the Browser Bridge, SL Now Playing may fall back to the media information provided by Windows, which can result in generic media detection.

Restarting the browser may also require the Browser Bridge to be restarted or re-enabled depending on the installation method being used.

---

## Download Link Does Not Work

The download link generated by the SL Now Playing HUD is temporary.

A download link:

- is intended for a single download
- expires after approximately **5 minutes**

If the link has expired or has already been used:

1. Return to Second Life.
2. Use the **Download** option on your SL Now Playing HUD again.
3. Open the newly generated download page.

You do not need to reuse the old link.

---

## PC Application Does Not Start

If the SL Now Playing PC Application does not start:

1. Make sure you downloaded it through the official TEKIZMO download process.
2. Try starting the application again.
3. Check whether Windows displayed a security notification.
4. Restart Windows and try again.

If the problem continues, contact TEKIZMO Support.

---

## Windows Displays a Security Warning

Windows security features may display a warning when starting downloaded applications.

Make sure your copy of SL Now Playing was obtained through the official download process provided by the SL Now Playing HUD.

Do not download SL Now Playing from unofficial third-party sources.

---

## Unpacker Does Not Respond

The Marketplace delivery includes the **SL Now Playing Unpacker HUD**.

To unpack:

1. Add the Unpacker to your avatar.
2. Click directly on the **UNPACK** button.
3. Wait for the confirmation message.

The contents will be delivered to:

**TEKIZMO - SL Now Playing**

After successful unpacking, the Unpacker should automatically detach.

You can attach it again later if you need to unpack another fresh copy.

---

## I Deleted My HUD

If you still have your original Marketplace delivery:

1. Add the SL Now Playing Unpacker again.
2. Click **UNPACK**.
3. A fresh copy will be delivered to your inventory.

If you no longer have the original delivery, use the available Second Life Marketplace redelivery option for your purchase.

---

## Still Having Problems?

Before contacting support, please note:

- what you were trying to do
- which player, browser or media source you were using
- what happened instead
- any error message you received

This information can help us identify the problem more quickly.

[Contact TEKIZMO Support](support.md)
